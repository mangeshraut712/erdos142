# Security

This repository is research notes and finite Python checkers. It is not
a networked service and has no production secrets.

## How to report a problem privately

If you find something that should not be discussed in a public issue
(for example a personal-data leak in a commit, or a vulnerability in
downstream packaging of these scripts), contact the author privately:

- Email: mbr63@drexel.edu
- GitHub: [@mangeshraut712](https://github.com/mangeshraut712)
- Prefer GitHub’s private vulnerability reporting on this repository
  if that feature is enabled.

Please include the file path, a short description, and whether the
issue is mathematical (incorrect claim) or operational.

Ordinary mathematical errors, counterexamples, and verifier bugs belong
in **public issues**. This project’s default is open discussion.
